## EFL Sprite v0.1.0 — 졸업 프로젝트 제출 버전

인터넷 없이 내 PC에서 돌아가는 영어 스피킹·라이팅 AI 코치 (TOEFL iBT 2026 형식 연습).
단국대학교 소프트웨어학과 졸업 프로젝트 · 곽태훈 (32210214)

### 다운로드
| 파일 | 대상 | 설치 방법 |
|---|---|---|
| `EFL Sprite_0.1.0_x64-setup.exe` | **Windows 10/11 (권장)** | 실행 → SmartScreen 창이 뜨면 *추가 정보 → 실행* (개인 개발자 앱이라 코드 서명 인증서가 없음) |
| `EFL-Sprite_0.1.0_macOS-AppleSilicon.zip` | macOS (Apple Silicon) | 압축 해제 → `EFL Sprite.app`을 응용 프로그램 폴더로 → 처음엔 **우클릭 → 열기**. "손상됨" 경고가 뜨면 터미널에서 `xattr -cr "/Applications/EFL Sprite.app"` |
| `EFL-Sprite_0.1.0_x64_test.msix` + `EFL-Sprite-test.cer` | Microsoft Store 패키지 시험 설치 | 관리자 PowerShell에서 `Import-Certificate -FilePath .\EFL-Sprite-test.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople` 후 msix 더블클릭 |

Microsoft Store 버전은 심사 통과 후 스토어에서 받을 수 있습니다 (Store ID `9MZT0SB40M2W`).

### 처음 실행
1. **시작하기** 화면 → *추천 모델 한 번에 받기* (약 5 GB, 처음 한 번만 인터넷 필요)
2. *예시 문제 추가* → 4개 유형 예시 문제 생성
3. *응시하러 가기* → 답안 작성 또는 녹음 → AI 채점

권장 사양: 메모리 16 GB 이상 · 저장 공간 6 GB · 마이크(스피킹)

### 주요 기능
- TOEFL iBT 2026 4개 유형: Listen and Repeat · Take an Interview · Write an Email · Academic Discussion
- 온디바이스 채점: Whisper(음성 인식) + 로컬 LLM + GECToR(학습자 문법 교정), 데이터 외부 전송 없음
- 점수마다 학생 문장 근거, 클릭형 교정 설명, 언어 지표, 이메일 요구사항 확인
- AI 문제 생성, `.eflsprite` 문제 파일 공유(카카오톡·USB), 문제 수정
- 교사 직접 첨삭, AI 교정 검토(✓/✗), 교사–AI 일치도

자세한 내용: [README](https://github.com/sonnykwack/efl-sprite#readme) · 결과보고서: `docs/report/`

> 점수는 AI 추정치이며 공식 점수가 아닙니다. TOEFL은 ETS의 등록 상표이며, 이 앱은 ETS와 관련이 없습니다.
