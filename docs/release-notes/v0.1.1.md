## EFL Sprite v0.1.1 — 화면 참조 작성과 실기기 테스트 반영

인터넷 없이 내 PC에서 돌아가는 영어 스피킹·라이팅 AI 코치 (TOEFL iBT 2026 형식 연습).
단국대학교 소프트웨어학과 졸업 프로젝트 · 곽태훈 (32210214)

### 다운로드
| 파일 | 대상 | 설치 방법 |
|---|---|---|
| `EFL Sprite_0.1.1_x64-setup.exe` | **Windows 10/11** | 실행 → SmartScreen 창이 뜨면 *추가 정보 → 실행* (개인 개발자 앱이라 코드 서명 인증서가 없음) |
| `EFL-Sprite_0.1.1_macOS-AppleSilicon.zip` | macOS (Apple Silicon) | 압축 해제 → `EFL Sprite.app`을 응용 프로그램 폴더로 → 처음엔 **우클릭 → 열기**. "손상됨" 경고가 뜨면 터미널에서 `xattr -cr "/Applications/EFL Sprite.app"` |
| `EFL-Sprite_0.1.1_x64_test.msix` + `EFL-Sprite-test.cer` | Microsoft Store 패키지 시험 설치 | 관리자 PowerShell에서 `Import-Certificate -FilePath .\EFL-Sprite-test.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople` 후 msix 더블클릭 |

Microsoft Store: https://apps.microsoft.com/detail/9MZT0SB40M2W (업데이트는 심사 후 자동 배포)

### 바뀐 점
- 화면 전체를 새로 작성 (응시, 녹음, 채점 결과, 교사 첨삭, 문제 관리·공유, 기록, 설정)
- 따라 말하기: 음성 인식이 숫자로 적어도("20") 단어("twenty")와 같게 채점
- 녹음: 시작 직후 첫 음성이 잘리지 않도록 대기, 따라 말하기의 침묵 자동 정지 제거("다음" 버튼으로 진행), 말소리 없는 인터뷰는 다시 녹음 안내
- 교사 첨삭: 저장 실패 표시, 빈 첨삭 저장 방지, AI 교정 위치 정확도 개선
- 설정: 모델 다운로드 실패 후 다시 시도 가능
- 문법 교정 설명: "eat snack → snacks"처럼 명사 복수형을 동사 수 일치로 잘못 설명하던 문제 수정
- 녹음 파일 경로 검사에 보안 테스트 추가, 저장·파일 오류 메시지 한국어화

기존에 받은 모델과 기록은 그대로 유지됩니다.
