# 시연 영상 대본 (약 8분)

발표자료 PPT는 필수 제출물이 아니므로, 이 대본은 **PPT 없이 앱 화면, 스토어 페이지, README만으로** 찍는 구성입니다.
도입과 마무리는 브라우저 화면 위에서 말하고, 가운데는 앱을 직접 조작합니다.

| 구간 | 화면 | 내용 | 길이 |
|---|---|---|---|
| O | Microsoft Store 페이지 → README | 소개, 문제, 해결 방법, 역할 분담 | 약 1분 30초 |
| D1–D7 | 앱 | 시작하기 → 문제 준비 → 라이팅 응시 → 채점 결과 → 교사 첨삭 → 스피킹 → 기록 | 약 5분 30초 |
| E | README → 스토어 페이지 | 검증 결과, 배포, 한계, 마무리 | 약 1분 |

- **권장 길이는 7–9분**입니다. 기능을 다 보여주면서도 지루하지 않은 길이이고, 채점 대기 구간을 잘라내면 자연스럽게 이 안에 들어옵니다.
- 시간이 부족하면 D2의 3·4번과 D6의 인터뷰를 빼세요(약 1분 단축). 핵심은 **D4 채점 결과**와 **D5 교사 첨삭**입니다.

## 녹화 전 준비 (15분)

**앱**
- [ ] 앱 창은 1440×900 정도로 맞추고, 화면 배율은 기본으로 둡니다. 알림을 꺼 주세요(방해 금지 모드).
- [ ] 설정 · 모델에서 Whisper small.en, Qwen2.5-7B, 문법 모델이 **설치된 상태**인지 확인합니다.
  - 시연 중에는 다운로드하지 않습니다. D1에서 "미리 받아 두었다"고 말하면 됩니다.
  - 설정 화면에는 내 컴퓨터 폴더 경로(`/Users/...`)가 나오므로 **영상에 띄우지 않습니다**.
- [ ] 채점 모델을 미리 한 번 실행해 둡니다. 첫 로딩이 오래 걸리기 때문입니다. 아무 답안이나 "빠른 채점"을 한 번 하면 됩니다.
- [ ] 기록 화면에 교사 점수가 들어간 기록(8건)이 남아 있는지 확인합니다.
- [ ] **AD 3 문제의 "Why or why not??"에서 물음표 하나를 지웁니다**(문제 관리 → 수정).
- [ ] 아래 **시연용 답안**을 메모장에 복사해 둡니다(붙여넣기용).
- [ ] `samples/sample-pack.eflsprite`를 바탕화면에 꺼내 둡니다(끌어다 놓기 시연용).

**브라우저** (도입·마무리용)
- [ ] 탭 두 개만 열어 둡니다.
  1. Microsoft Store 페이지: https://apps.microsoft.com/detail/9MZT0SB40M2W
  2. GitHub README: https://github.com/sonnykwack/efl-sprite
- [ ] 다른 탭과 북마크 바는 숨깁니다(`⌘⇧B`). 개인 정보가 화면에 나오지 않게 하기 위해서입니다.

**녹화 도구**
- [ ] macOS `⌘⇧5` → "선택 부분 기록" → 옵션에서 마이크를 선택합니다.
- [ ] 기다리는 구간은 나중에 잘라낼 것이므로 끊지 말고 계속 녹화해도 됩니다.

### 시연용 답안 (Email — 수준 낮은 답안, 피드백이 풍부하게 나옴)
```
Hello manager.
Construction is too noisy. It start very early so I can not sleep. Every day I am tired and my grade is going down maybe. I think this is not fair because we pay dormitory fee. Please stop the construction in morning or give us some discount. I want answer quickly.
Thank you.
```
> 이 답안은 기존 **"Email 2 — Early-morning construction"** 문제로 응시하세요. 이미 그 문제에 결과가 있어도 새로 응시하면 됩니다.

## D. 앱 시연 (약 5분 30초)

### D1. 시작하기 (30초)
**화면**: 앱 실행 → 시작하기 화면
**말**: "앱을 처음 켜면 시작하기 화면이 엔진 확인, AI 모델 받기, 문제 준비, 첫 응시까지 네 단계로 안내합니다. 모델은 처음 한 번만 내려받고, 그 뒤로는 인터넷 없이 동작합니다. 저는 미리 받아 두었습니다."
**동작**: "예시 문제 추가" 클릭 → "예시 문제 ○개를 추가했어요" 표시

### D2. 문제 준비: AI 생성 · 공유 · 수정 (1분)
**화면**: 문제 관리
1. **✨ AI로 문제 만들기**: 유형 *이메일*, 주제 *campus life*, 개수 1 → 만들기
   - 기다리는 구간은 편집으로 잘라냅니다.
   - **말**: "강사가 유형과 주제만 고르면 PC 안의 AI가 문제 초안을 만들고, 강사가 확인한 뒤 저장합니다."
   - 초안의 요구사항 세 줄을 보여준 뒤 "이 문제 저장"을 누릅니다.
2. **파일로 내보내기**: 문제 2–3개 체크 → 세트 이름 "3주차 라이팅", 만든 사람 "EK 조교" → 저장
   - **말**: "만든 문제는 파일 하나로 내보내 카카오톡이나 USB로 학생에게 보낼 수 있습니다."
3. **끌어다 놓기**: 바탕화면의 `sample-pack.eflsprite`를 앱 창에 드래그 → 미리보기 → "○개 문제 추가"
   - **말**: "학생은 받은 파일을 끌어다 놓기만 하면 됩니다. 이미 있는 문제는 건너뜁니다."
4. (선택) 아무 문제의 **수정** → 오른쪽 미리보기를 보여주고 "취소"
   - **말**: "수정 화면에서는 학생에게 보일 화면과 AI가 채점할 요구사항을 바로 확인할 수 있습니다."

### D3. 라이팅 응시 (40초)
**화면**: 응시 → "Email 2 — Early-morning construction" 시작
**말**: "실제 시험처럼 제한 시간이 흐르고 단어 수가 표시됩니다. 시간이 끝나면 자동으로 제출됩니다."
**동작**: 시연용 답안 붙여넣기 → 제출 → 진행 단계 화면(문법 모델 → AI 채점 → 한국어 번역)
- 기다리는 구간은 잘라내고 "(채점 약 40초 — 편집으로 생략)" 자막을 넣습니다.

**말**: "답안은 먼저 저장된 뒤, 문법 모델, AI 채점, 한국어 번역 순서로 모두 PC 안에서 처리됩니다."

### D4. 채점 결과 (1분 20초) — 가장 중요한 장면
위에서 아래로 천천히 스크롤하며 다음 순서로 보여줍니다.
1. **추정 밴드와 점수 상한**
   - **말**: "추정 밴드와 함께, 분량이 부족하고 명령조 표현이 있어 점수 상한이 걸린 이유를 보여줍니다. 점수는 AI 추정치이고 ETS 공식 점수가 아니라는 것도 함께 표시합니다."
2. **요구사항 체크**
   - **말**: "이메일이 요구한 세 가지를 다뤘는지 근거 문장과 함께 확인합니다."
3. **항목별 점수**
   - **말**: "점수마다 학생 본인의 문장을 근거로 인용합니다."
4. **언어 지표**
   - **말**: "어휘 다양성, 문장 구조, 오류 밀도 같은 지표는 코드가 직접 측정하기 때문에 매번 같은 결과가 나옵니다."
5. **밑줄 클릭**: "It **start**" 클릭 → 교정 카드
   - **말**: "밑줄을 누르면 고친 표현, 이 문장에서 틀린 이유, 문법 원칙과 예문이 나옵니다. 이 오류는 학습자 영어로 학습한 문법 모델이 찾았습니다."
6. "**I want answer quickly**" 클릭 → 어조 카드
   - **말**: "이메일의 명령조 표현은 규칙 검사가 잡아내고, 정중한 표현으로 바꿔 줍니다."

### D5. 교사 직접 첨삭 (1분)
**동작**: 결과 화면의 "✏️ 직접 첨삭"
1. 에세이에서 "**we pay dormitory fee**"를 드래그 → 유형 *관사* → 고친 표현 "we pay the dormitory fee" → 코멘트 "특정한 기숙사비이므로 the가 필요해요." → 첨삭 추가
   - **말**: "강사는 틀린 부분을 드래그하고, 오류 유형을 고른 뒤 고친 표현과 코멘트를 남깁니다."
2. AI 교정 하나에 **✓ 맞음**, 다른 하나에 **✗ 틀림**을 누릅니다.
   - **말**: "AI의 교정도 하나씩 맞음·틀림으로 검토합니다. 틀림으로 표시한 교정은 학생에게 보이지 않습니다."
3. **고친 글 미리보기**를 보여줍니다.
4. 오른쪽 위 "결과 보기" → "선생님" 배지가 붙은 교정을 보여줍니다.
   - **말**: "학생 화면에는 선생님의 첨삭이 AI 교정보다 먼저 보입니다."

### D6. 스피킹 (50초)
**화면**: 응시 → "예시 · Listen & Repeat — Library tour"
**동작**: 시작 → 문장 듣기 → 따라 말하기
- 3번 문장은 일부러 "five books"를 "five book"으로 말합니다.
- 나머지는 정확히 말합니다.

**말**: "시스템 음성이 문장을 읽어주면 따라 말하고, 다 말하면 '다음'을 누릅니다. 중간에 잠깐 멈춰도 녹음이 끊기지 않고, 제한 시간이 끝나면 자동으로 넘어갑니다."

**결과 화면**: 단어별 표시 → "▶ 녹음 듣기"
- **말**: "음성 인식 결과를 원문과 단어 단위로 비교해, 틀리게 말하거나 빠뜨린 단어를 보여주고 내 녹음을 다시 들을 수 있습니다. 숫자를 '20'처럼 숫자로 받아 적어도 'twenty'와 같게 채점합니다."

> 시간이 남으면 인터뷰 문제를 하나 녹음해 결과 화면만 보여줘도 됩니다.

### D7. 기록 (20초)

## 편집 팁
- 채점 대기, 모델 로딩처럼 **기다리는 구간은 잘라내고** "(채점 약 40초 — 편집으로 생략)" 같은 자막을 넣습니다. 정직하면서도 지루하지 않습니다.
- 화면 글씨가 작으면 편집 때 결과 화면 일부를 확대합니다. 특히 D4의 교정 카드와 D6의 단어별 표시가 그렇습니다.
- 말은 대본을 그대로 읽기보다 **구간별로 끊어서 녹음**하면 편합니다. 틀린 구간만 다시 찍어 이어 붙이면 됩니다(Mac은 iMovie).
- 배경음악은 넣지 않거나 유튜브 오디오 보관함의 무료 음악만 씁니다(저작권 신고 방지).
- 유튜브 업로드 시 공개 범위는 **일부 공개**로 하면 링크가 있는 사람만 볼 수 있습니다.
