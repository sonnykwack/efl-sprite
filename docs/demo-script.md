# 시연 영상 대본 (약 10분)

슬라이드(선택): 발표자료 PPT는 필수 제출물이 아니므로, 만들지 않으면 A·C 구간은 앱 화면 위에 말로만 소개하거나 결과보고서의 그림·표를 띄워 설명해도 됩니다. PPT를 만들면 내레이션은 각 슬라이드의 **발표자 노트**에 넣어 두세요.

| 구간 | 내용 | 길이 |
|---|---|---|
| A | 슬라이드 1–5 (소개 · 문제 · 해결 · 구조 · 시연 순서) | 약 2분 30초 |
| B | 앱 시연 D1–D7 | 약 6분 |
| C | 슬라이드 6–10 (결과 · 역할 · 배포 · 한계 · 마무리) | 약 2분 |

---

## 녹화 전 준비 (15분)
- [ ] 앱 창 크기 1440×900 정도, 화면 배율 기본. 알림 끄기(방해 금지 모드)
- [ ] 설정 · 모델: Whisper small.en, Qwen2.5-7B, 문법 모델 **설치된 상태**
  - 시연 중에 다운로드하지 않아요. D1에서 "이미 받아 둔 상태"라고 말하면 됩니다.
- [ ] 채점 모델을 미리 한 번 실행해 두기. 첫 로딩이 오래 걸리기 때문이에요.
  - 아무 답안이나 "빠른 채점" 한 번 하면 됩니다.
- [ ] 기록 화면에 교사 점수가 들어간 기록(8건)이 남아 있는지 확인
- [ ] 아래 **시연용 답안**을 메모장에 복사해 두기 (붙여넣기용)
- [ ] `samples/sample-pack.eflsprite`를 Finder의 바탕화면에 꺼내 두기 (끌어다 놓기 시연용)
- [ ] 녹화 도구: macOS `⌘⇧5` → "선택 부분 기록" → 옵션에서 마이크 선택
  - 기다리는 구간은 나중에 잘라낼 거라 끊지 말고 계속 녹화해도 됩니다.

### 시연용 답안 (Email — 수준 낮은 답안, 피드백이 풍부하게 나옴)
```
Hello manager.
Construction is too noisy. It start very early so I can not sleep. Every day I am tired and my grade is going down maybe. I think this is not fair because we pay dormitory fee. Please stop the construction in morning or give us some discount. I want answer quickly.
Thank you.
```
> 이 답안을 쓰려면 예시 문제 중 이메일이 아니라 기존 **"Email 2 — Early-morning construction"** 문제를 고르세요. 이미 결과가 있다면 그 기록을 열어 보여줘도 됩니다.

## B. 앱 시연

### D1. 시작하기 (40초)
**화면**: 앱 실행 → 시작하기 화면
**말**: "앱을 처음 켜면 시작하기 화면이 나옵니다. 엔진 확인, AI 모델 받기, 문제 준비, 첫 응시까지 네 단계로 안내합니다. 모델은 처음 한 번만 약 5GB를 내려받고, 그 뒤로는 인터넷 없이 동작합니다. 저는 미리 받아 두었습니다."
**동작**: "예시 문제 추가" 클릭 → "예시 문제 4개를 추가했어요" 표시

### D2. 문제 준비: 공유 · AI 생성 · 수정 (1분 10초)
**화면**: 문제 관리
1. **AI로 문제 만들기**: 유형 *이메일*, 주제 *campus life*, 개수 1 → 만들기
   - 기다리는 동안 컷 편집
   - **말**: "강사가 유형·주제·난이도만 고르면 로컬 AI가 문제 초안을 만들고, 강사가 확인한 뒤 저장합니다."
   - 초안의 요구사항 세 줄을 보여준 뒤 "이 문제 저장"
2. **파일로 내보내기**: 문제 2–3개 체크 → 세트 이름 "3주차 라이팅", 만든 사람 "EK 조교" → 저장
   - **말**: "만든 문제 세트는 파일 하나로 내보내 카카오톡이나 USB로 학생에게 보낼 수 있습니다."
3. **끌어다 놓기**: 바탕화면의 `sample-pack.eflsprite`를 앱 창에 드래그 → 미리보기 → "4개 문제 추가"
   - **말**: "학생은 받은 파일을 창에 끌어다 놓기만 하면 문제가 한 번에 추가됩니다. 이미 있는 문제는 건너뜁니다."
4. (선택) 아무 문제의 **수정** → 오른쪽 미리보기를 보여주고 "취소"
   - **말**: "수정 화면에서는 학생에게 보일 화면과, AI가 채점할 요구사항이 바로 보입니다."

### D3. 라이팅 응시 (50초)
**화면**: 응시 → "Email 2 — Early-morning construction" 시작
**말**: "실제 시험처럼 제한 시간이 흐르고, 시간이 끝나면 자동 제출됩니다."
**동작**: 시연용 답안 붙여넣기 → 제출 → 진행 단계 화면(문법 모델 → AI 채점 → 한국어 번역)
- 기다리는 구간 컷 편집
**말**: "답안은 채점 전에 먼저 저장되고, 문법 모델, AI 채점, 한국어 번역 순서로 PC 안에서 처리됩니다."

### D4. 채점 결과 (1분 20초) — 가장 중요한 장면
위에서 아래로 천천히 스크롤하며 아래 순서로 보여주세요.
1. **추정 밴드 + 점수 상한**
   - **말**: "추정 밴드와 함께, 분량 부족과 명령조 표현 때문에 점수 상한이 적용된 이유를 보여줍니다."
2. **요구사항 체크**
   - **말**: "이메일이 요구한 세 가지를 다뤘는지 근거 문장과 함께 확인합니다."
3. **항목별 점수**
   - **말**: "점수마다 학생 본인의 문장을 근거로 인용합니다."
4. **언어 지표**
   - **말**: "어휘 다양성, 문장 구조, 문법 정확성 같은 지표는 코드가 직접 측정해 매번 같은 결과를 줍니다."
5. **밑줄 클릭**: "It **start**" 클릭 → 교정 카드
   - **말**: "밑줄을 누르면 고친 표현, 이 문장에서 틀린 이유, 문법 원칙과 예문이 나옵니다. 이 오류는 학습자 영어로 학습한 문법 모델이 찾았습니다."
6. "**I want answer quickly**" 클릭 → 어조 규칙 카드
   - **말**: "이메일의 명령조 표현은 규칙 검사가 잡고, 정중한 표현으로 바꿔 줍니다."

### D5. 교사 직접 첨삭 (1분)
**동작**: 결과 화면 "✏️ 직접 첨삭"
1. 에세이에서 "**we pay dormitory fee**"를 드래그 → 유형 *관사* → 고친 표현 "we pay the dormitory fee" → 코멘트 "특정한 기숙사비이므로 the가 필요해요." → 첨삭 추가
   - **말**: "강사는 틀린 부분을 드래그하고, 오류 유형을 고른 뒤 고친 표현과 코멘트를 남깁니다."
2. AI 교정 하나에 **✓ 맞음**, 하나에 **✗ 틀림** (예: "maybe" 삭제)
   - **말**: "AI의 교정도 하나씩 맞음·틀림으로 검토합니다. 틀림으로 표시한 교정은 학생에게 보이지 않습니다."
3. 왼쪽 아래 **고친 글 미리보기** 보여주기
4. 오른쪽 위 "결과 보기" → "선생님" 배지가 붙은 교정 보여주기
   - **말**: "학생 화면에는 선생님의 첨삭이 AI보다 우선해서 보입니다."

### D6. 스피킹 (50초)
**화면**: 응시 → "예시 · Listen & Repeat — Library tour"
**동작**: 시작 → 문장 듣기 → 따라 말하기
- 3번 문장은 일부러 "five books"를 "five book"으로 말하기
- 나머지는 정확히 말하기
**말**: "시스템 음성이 문장을 읽어주면 따라 말하고, 다 말했으면 '다음'을 누릅니다. 연습 중에 잠깐 멈춰도 녹음이 끊기지 않고, 제한 시간이 끝나면 자동으로 넘어갑니다."
**결과 화면**: 단어별 표시 + "▶ 녹음 듣기"
- **말**: "음성 인식 결과를 원문과 단어 단위로 비교해서, 틀리게 말한 단어와 빠뜨린 단어를 보여주고 내 녹음을 다시 들을 수 있습니다."
> 시간이 남으면 인터뷰 문제를 하나 녹음해 결과 화면만 보여줘도 됩니다.

### D7. 기록 (20초)
**화면**: 기록
**말**: "기록 화면에서는 학생별 결과와 함께, 강사 점수와 AI 점수의 일치도, 그리고 강사가 검토한 AI 교정의 정확도를 볼 수 있습니다."
